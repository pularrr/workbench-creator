# P1 阶段文档 · v0.5–v0.6 检索增强与模板包

> 阶段目标：在 P0 数据链路修复的基础上，提升材料检索质量、扩展学校模板支持、增强文档解析能力，并完成客户端 UI 的可验证交付。
> 预计版本：v0.5.0（rerank + 模板包）→ v0.6.0（DeepDoc/TSR/OCR + client UI 校验）
> 状态：进行中

---

## 一、阶段目标与范围

### 1.1 目标

| 编号 | 目标 | 验收指标 |
|---|---|---|
| G1 | 混合检索引入 rerank 层，提升 top-k 相关度 | 检索结果 top-3 命中率较 baseline 提升 ≥ 20%（人工标注集评估） |
| G2 | 支持学校/期刊模板包导入，不再硬编码单一硕士模板 | 可导入 ≥ 3 套模板（通用硕士、通用本科、IEEE 会议），导入后 set_plan 可用 |
| G3 | 文档解析支持表格结构还原（TSR）与扫描 PDF OCR | 含表格的 docx/pdf 导入后，表格内容以 Markdown 表格形式进入分块 |
| G4 | 客户端 UI（会话头部"论文工作台"按钮）可验证、可诊断 | `scripts/verify-client-ui.mjs` 一键校验按钮注入与 3199 连通性 |

- rerank provider 抽象层（Cohere / Voyage / 本地 cross-encoder 兜底）
- 模板包 JSON Schema 与导入工具

- client UI 校验脚本
- 对应单元测试与回归测试

**Out scope**（推迟到 P2/P3）：

## 二、需求拆解

### 2.1 G1 · rerank 层

**现状**：`src/source-index.js` 的 `hybridSearch` 用固定权重 `keyword*0.45 + vector*0.55` 排序，无二次重排。短查询（如"雷达"）召回噪声大。

**需求**：
1. 新增 `src/reranker.js`，定义 `Reranker` 接口：`rerank(query, passages, options) → Promise<Array<{index, score, text}>>`。
2. 三种 provider：
   - `cohere`：调用 Cohere Rerank API（`/v1/rerank`），需 apiKey。
   - `voyage`：调用 Voyage AI rerank API。
   - `local`（默认兜底）：基于 BM25 + 字符 n-gram 重叠的轻量重排，无需外部依赖。
3. `domain-store.js` 的 `searchSources` 增加可选参数 `rerank: { provider, topK, apiKey? }`，默认 `provider: 'local'`。
4. rerank 结果的 `score` 必须是有限浮点数（过 `toLosslessJson`），禁止 NaN。

**接口设计**：
```js
// src/reranker.js
export function createReranker(provider, options = {})
export async function rerankPassages(reranker, query, passages, topK = 8)
```

### 2.2 G2 · 学校模板包

**现状**：`src/master-template.js` 硬编码一套 8 节硕士模板，无法适配本科/博士/期刊/学校自定义要求。

**需求**：
1. 定义模板包 JSON Schema（`docs/template-pack-schema.json`）：
   ```json
   {
     "id": "string",
     "name": "string",
     "degreeType": "bachelor|master|doctor|conference",
     "targetWords": 30000,
     "sections": [
       {"title": "string", "ratio": 0.1, "objective": "string",
        "logic": [{"purpose": "string", "transition": "string"}]}
     ]
   }
   ```
2. 新增 `src/template-pack.js`：`loadTemplatePack(filePath)`、`validateTemplatePack(pack)`、`listBuiltinPacks()`。
3. 内置 3 套模板：`generic-master`（现有）、`generic-bachelor`、`ieee-conference`。
4. 新增工具 `thesis_import_template_pack`：从本地 JSON 文件导入模板包，存入项目的 `templatePacks`。
5. `thesis_apply_default_master_template` 增加 `packId` 参数，可选择用哪套模板生成大纲。

### 2.3 G3 · 表格 TSR 与扫描 OCR

**现状**：`src/document-parser.js` 用 `officeparser` 解析，`ocr: false`，表格被拍平为纯文本，扫描 PDF 完全无法提取。

**需求**：
1. `parseApprovedDocument` 增加 `options.enableOcr`（默认 false），开启后对扫描 PDF 调用 OCR。
2. OCR provider 抽象：`tesseract`（本地，`tesseract.js`）/ `paddleocr`（HTTP 服务）/ `none`。
3. 表格还原：officeparser 的 AST 中表格节点转为 Markdown 表格（`| col | col |`），保留表头。
4. 解析结果的 `metadata` 增加 `tablesExtracted: number`、`ocrApplied: boolean`。

### 2.4 G4 · client UI 校验

**现状**：`client.js` 注入会话头部按钮，但无法验证 DSH web 产物是否真的打包了该插件，用户反馈"看不到按钮"时无诊断手段。

**需求**：
1. 新增 `scripts/verify-client-ui.mjs`，一键检查：
   - 3199 工作台 HTTP 连通性（`/api/projects` 返回 200）
   - DSH web profile 中 `dsh-thesis-agent` 已安装（`dsh plugin --profile web list`）
   - `client.js` 语法正确（`node --check`）
   - `package.json` 的 `dsh.client.inject` 包含 `@deepseek-ai/dsh-client-ui-conversation`
   - 输出诊断报告与修复建议
2. 纳入 `npm run verify` 脚本。

## 三、技术方案与架构

### 3.1 模块依赖图

```
thesis_search_sources (index.js)
  └─ domain-store.searchSources
       ├─ source-index.hybridSearch (baseline)
       └─ reranker.rerankPassages (可选，P1 新增)
            ├─ CohereReranker
            ├─ VoyageReranker
            └─ LocalReranker (BM25 + n-gram，默认)

thesis_import_template_pack (index.js, P1 新增)
  └─ domain-store.importTemplatePack
       └─ template-pack.loadTemplatePack / validateTemplatePack

document-parser.parseApprovedDocument
  ├─ officeparser (现有)
  ├─ tableExtractor (P1 新增，AST→Markdown 表格)
  └─ ocrProvider (P1 新增，可选)
```

### 3.2 配置项

| 配置 | 默认 | 说明 |
|---|---|---|
| `rerank.provider` | `'local'` | rerank 提供商 |
| `rerank.topK` | `8` | rerank 后保留条数 |
| `rerank.apiKey` | `undefined` | Cohere/Voyage API Key（仅内存，不落盘） |
| `ocr.enabled` | `false` | 是否启用 OCR |
| `ocr.provider` | `'tesseract'` | OCR 提供商 |
| `templatePack.default` | `'generic-master'` | 默认模板包 |

## 五、风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| Cohere/Voyage API 不可用或限流 | rerank 失败 | 默认 local provider；外部 provider 失败时自动降级 local 并记录 warning |
| OCR 依赖（tesseract）未安装 | 扫描 PDF 无法解析 | OCR 默认关闭；开启时检测依赖并给出安装指引 |
| 模板包 JSON 格式错误 | 导入失败 | 严格 Schema 校验，错误时返回具体字段位置，不写入项目 |
| rerank 分数 NaN | 工具桥再次断裂 | rerank 结果统一过 `toLosslessJson`，单测覆盖 NaN 场景 |
